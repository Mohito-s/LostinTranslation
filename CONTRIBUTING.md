# CONTRIBUTING

Спасибо за интерес к LostInTranslation API! Ниже — как помочь проекту.

## Как внести вклад

1. **Fork** репозитория и создайте ветку от `main`:
   ```bash
   git checkout -b feature/my-change
   ```
2. Убедитесь, что проект проходит проверки перед коммитом:
   ```bash
   npm install
   npm run lint    # tsc --noEmit
   npm test        # vitest
   ```
3. Напишите понятный коммит (по возможности по-английски, точечно и маленький).
4. Откройте **Pull Request** по шаблону `.github/PULL_REQUEST_TEMPLATE.md`.
5. CI проверит lint, тесты и сборку автоматически.

## Какой вклад полезен

- Фиксы багов и опечаток
- Тесты (Vitest) для `src/lib/*`
- Новые mock-примеры «культурных потерь» в `src/lib/analyze.ts` и `src/lib/enhance.ts`
- Доступность и полировка UI (`src/App.tsx`, `src/components/*`)
- Документация (README, ROADMAP, гайды)
- Доп-кейсы: новый язык, региональный вариант, диалект

## Правила

- Не коммитьте секреты: `.env`, `local_db.json`, логи — в `.gitignore`.
- Для реальных вызовов Gemini ключ берётся только из `process.env.GEMINI_API_KEY`.
- В проде обязателен `SESSION_SECRET` (без него сервер не стартует).
- Следуйте AGPL-3.0: любые изменения также открываются под этой лицензией.

## Анализ текста и тестовые ключи

- Без `GEMINI_API_KEY` сервер работает на mock-ответах — это удобно для локальной разработки и тестов.
- Демо-ключи сидируются только при `SEED_DEMO_KEYS=true`. В проде держите `false` (по умолчанию).

## Стиль

- TypeScript strict-ish — проект проходит `tsc --noEmit` без `strict: true`; не ломайте это.
- Форматтер не подключён — старайтесь сохранять чистые отступы в 2 пробела и стиль соседнего кода.
